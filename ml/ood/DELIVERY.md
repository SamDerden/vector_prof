## Запуск

```bash
python ml/ood/workbench.py train
python ml/ood/workbench.py predict --question 'А сколько учиться?'
python ml/ood/workbench.py compare
python -m unittest discover -s ml/ood -p 'test_*.py'
```

Реальное сравнение: задать вне репозитория `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`, `LLM_EMBEDDINGS_MODEL` (или поддерживаемые AI_* алиасы), затем `python ml/ood/workbench.py compare --provider`. Ключ в чат не присылать. Команда использует до 380 обучающих embeddings, 150 оценочных embeddings и 150 последовательных LLM-запросов, без скрытых повторов. При отсутствии доступа записывает blocked, а не фиктивные метрики. При сбое сохраняет уже завершённые разделы. Латентность embeddings включает сетевой запрос; TF-IDF — локальное предсказание. Это не сравнение серверного SLA.

Сохранённый joblib — только наш собственный артефакт, не загружать непроверенные pickle/joblib. Manifest проверяет хэши модели и данных от случайного рассогласования; он не обеспечивает защиту от злоумышленника, заменившего оба файла. Scores — некалиброванные вероятности классификатора, не достоверность рекомендации.
