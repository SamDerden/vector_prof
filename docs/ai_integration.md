# Передача JSON AI-инженеру — Data Freeze 1

## Файлы

- `NAVIGATOR_DATA_FREEZE_1_FOR_AI.json` — полный денормализованный JSON по шаблону заказчика.
- `NAVIGATOR_DATA_FREEZE_1_SCHEMA.json` — JSON Schema draft 2020-12.
- Excel-книга `NAVIGATOR_DATA_FREEZE_1_MASTER_12_SHEETS.xlsx` остаётся источником истины.

## Структура

`meta`, `industries`, `skills`, `organizations`, `professions`, `trials`, `education_programs`, `profession_first_steps`, `self_guided_steps`.

`professions[].riasec` — шесть значений 0..1. 
`professions[].current_market_state` — последние ориентиры из Excel, НЕ проверенный текущий рынок.
`professions[].vacancy_history` — **только реальные строки из таблицы vacancy_snapshot**; в текущей базе по одной исторической строке на профессию. Не создавать несуществующие временные ряды.
`professions[].skills` — все связи profession_skill, включая исключённые из рекомендательного прототипа. **Перед расчётом ранжирования фильтровать `matching_eligible == 'yes_provisional'`.** `matching_weight` не нужно дополнительно умножать на `matching_prevalence_weight` без отдельной спецификации скоринга.
`professions[].programs` — связи из program_profession; `fit_level` различает 'прямая', 'смежная', 'знакомство'. Кружки не заменяют СПО/ВО.
`professions[].trials` — связи из trial_profession; `connection_type` direct / related / exploratory, доступность берётся из `availability_status`. Мероприятия со статусом 'прошло' НЕ показывать как открытые.
`professions[].first_steps` — авторские самостоятельные сценарии (только 42 профессии); это **не внешние мероприятия**.
Отдельные полные массивы `trials` и `education_programs` нужны для глобального поиска без выбранной профессии.

## Важные правила импорта

1. Считать идентификаторы строками и не преобразовывать коды специальностей в даты/числа.
2. `null` = неизвестно или неприменимо; не подменять 0.
3. Нельзя утверждать, что мероприятие сейчас доступно, только на основании ссылки на источник.
4. Для региональной выдачи географию проверять на уровне площадки и муниципалитета; `Онлайн` не является городом, а в историческом каталоге могут быть внeрегиональные примеры.
5. Каталоги не являются независимыми копиями исходных сущностей: вложенные массивы — денормализованные представления тех же связей.
6. Не проводить модельный fine-tuning на JSON как будто это верифицированная истина; сначала проверять retrieval, ранжирование и объяснения на тест-кейсах.
