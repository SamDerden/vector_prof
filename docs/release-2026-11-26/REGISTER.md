## Найденные и устранённые дефекты

1. `prof_…` сворачивались на фронтенде в `none`, backend/БД принимали только UUID. Теперь формат поддержан по всему пути; старые маршруты сохранены. Ранее смешанные данные автоматически не разделяются.
2. В API маршрута отсутствовал ID для экспорта/отзыва. Добавлено необязательное обратно совместимое поле `route_id`.
3. Валидация freeze-индекса могла пропустить дубли при совпадающем количестве. Добавлены проверки реального множества профессий, модели, источника, векторов и уникальности chunks; runtime использует их.
4. Недоступный/повреждённый файл индекса теперь позволяет lexical fallback вместо ошибки чтения.

## Не считать выпуск готовым

До снятия P0 по реальной почте, RAG/AI, импорту PDF, мастерской и сквозному UI — NO-GO полного scope из плана. Доступность существующего сайта не означает готовность этих функций. Для сокращённого пилота нужен отдельный согласованный scope.
